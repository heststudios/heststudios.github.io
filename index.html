— About

The studio

Who we are

Hest Studios is an independent one-person mobile game studio based in Turkey. We build games from scratch — no engines we don't understand, no asset packs we didn't make, no mechanics we copied.

Every shader, every line of code, every minaret, every city silhouette is hand-crafted. We ship slowly, deliberately, and only when something feels right.

What we make

We focus on original mobile games in genres we love: idle tycoon, single-tap reflex, puzzle. We're not chasing trends or rebuilding hits that already exist.

If you've played a game like ours before, we did something wrong.
